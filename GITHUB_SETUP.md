## Upload using the GitHub website

1. Create a new repository named `2DOF-Robotic-Manipulator-PID-Control`.
2. Do not initialise it with another README if you are uploading this package.
3. Choose **Add file > Upload files**.
4. Upload all files and folders from this project package.
5. Commit the files.
6. Add the suggested topics under the repository's **About** section.

## Upload using Git

```bash
git init
git add .
git commit -m "Initial commit: 2-DOF robotic manipulator"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/2DOF-Robotic-Manipulator-PID-Control.git
git push -u origin main
```

Replace `YOUR-USERNAME` with your GitHub username.
